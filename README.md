# World Nuclear Reactor Analysis Dashboard

## Project Overview

The World Nuclear Reactor Analysis Dashboard is an interactive
Power BI project designed to analyze the global nuclear reactor
fleet, reactor technology, reactor ageing, operational status,
generating capacity, operators, and suppliers.

The project transforms nuclear industry data into interactive
visualizations to support data exploration and comparative analysis
across countries, reactor types, and organizations.

## Objectives

- Analyze the global nuclear reactor fleet.
- Compare operational and suspended reactors.
- Explore total nuclear generating capacity by country.
- Analyze reactor technology distribution.
- Examine reactor age bands and ageing patterns.
- Compare reactor construction and connection decades.
- Evaluate nuclear power operators and equipment suppliers.
- Identify differences in nuclear capacity across countries.

## Dashboard Pages

### 1. Global Nuclear Fleet Overview

This page provides an overview of the global nuclear reactor fleet.

Key insights include:
- Total and operational reactors.
- Suspended reactor count.
- Total generating capacity.
- Average reactor age.
- Reactor status distribution.
- Reactor types and their counts.
- Country-level capacity comparisons.

![Global Nuclear Fleet Overview](screenshots/01_Global_Nuclear_Fleet_Overview.png)

### 2. Reactor Technology & Ageing Analysis

This page explores reactor age, technology, and historical
development patterns.

Key insights include:
- Distribution of reactors by age band.
- Oldest reactor units in the dataset.
- Average reactor age by region.
- Average build duration by connection decade.
- Reactor connections across different decades.

![Reactor Technology and Ageing Analysis](screenshots/02_Reactor_Technology_Ageing_Analysis.png)

### 3. Operators, Suppliers & Capacity Insights

This page examines nuclear power operators, reactor suppliers,
and country-level fleet characteristics.

Key insights include:
- Generating capacity by operator.
- Generating capacity by supplier.
- Reactor counts by country.
- Total generating capacity by country.
- Average reactor age by country.
- Reactor-level operational information.

![Operators, Suppliers and Capacity Insights](screenshots/03_Operators_Suppliers_Capacity_Insights.png)
